# COMP1238 Study Notes

## Week 1 - History

- Writing systems allow people to record, store, and share information.
- Cuneiform was an ancient writing system used in Mesopotamia.

## Week 2 - Bits and Bytes

- A bit is the smallest unit of digital information and can have a value of 0 or 1.
- Eight bits make one byte, which is commonly used to represent digital information.

## Week 3 - Representing Numbers

- Computers use binary numbers, which are based on 0 and 1.
- Hexadecimal is a base-16 number system that uses the digits 0-9 and the letters A-F.

## Week 4 - Files and Search

- File paths can be used to locate files and folders on a computer.
- Wildcard characters, such as * and ?, represent unknown characters in file searches.

## Week 5 - Command Line

- The command line allows users to interact with a computer by typing commands.
- Linux commands such as `cat` can display the contents of files, including files with unusual names.
